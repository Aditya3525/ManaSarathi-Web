JavaScript Fundamentals

The building block of everything. Before Express, before Prisma — it's all JavaScript under the hood.

1. Variables — Storing Data

There are three ways to declare a variable in modern JavaScript. You should use const and let — never var.

const
Cannot be reassigned
let
Can be reassigned
const userId = "clx123abc";  // Fixed — won't change
let moodScore = 7;          // Can change later

moodScore = 8;              // ✅ OK — let allows this
userId = "xyz";             // ❌ Error — const doesn't allow this
📂 In ManaSarathi

In server.ts, const PORT = 5000 is used because the port number never changes. Variables like user input or loop counters use let.

2. Data Types

JavaScript has a handful of core data types you will use constantly:

const name     = "Aditya";       // string
const age      = 22;            // number
const isPremium = false;        // boolean
const nothing  = null;          // null — intentionally empty
const missing  = undefined;     // undefined — not yet set

// object — groups multiple values
const user = {
  id: "clx123abc",
  name: "Aditya",
  isPremium: false
};

// array — ordered list of values
const moods = ["Great", "Good", "Okay", "Struggling"];

Accessing Object Properties

console.log(user.name);        // "Aditya"
console.log(user["isPremium"]); // false
console.log(moods[0]);          // "Great"  (arrays start at index 0)

3. Functions — Reusable Blocks of Logic

A function is a named block of code you can call repeatedly. In ManaSarathi's backend, almost everything is a function.

// Classic function declaration
function greetUser(name) {
  return "Hello, " + name + "!";
}

// Arrow function (modern, preferred style)
const greetUser = (name) => {
  return `Hello, ${name}!`;  // Template literal
};

// Short arrow function (implicit return)
const double = (n) => n * 2;

console.log(greetUser("Aditya"));  // "Hello, Aditya!"
console.log(double(5));             // 10
📂 In ManaSarathi

Every middleware, controller, and route handler is an arrow function:
const authenticate = async (req, res, next) => { ... }

4. Arrays & Loops

Arrays let you work with lists of data. Three tools you'll use constantly:

const scores = [85, 72, 91, 60];

// .map() — transform each item into something new
const doubled = scores.map((s) => s * 2);
// [170, 144, 182, 120]

// .filter() — keep only items that match a condition
const passing = scores.filter((s) => s >= 75);
// [85, 91]

// .find() — get the FIRST item that matches
const firstHigh = scores.find((s) => s > 80);
// 85

// for...of loop — iterate over items
for (const score of scores) {
  console.log(score);
}

5. Destructuring — Cleaner Code

Destructuring lets you unpack values from objects and arrays into named variables in one line.

const user = { name: "Aditya", mood: "Good", intensity: 7 };

// Without destructuring (verbose)
const name      = user.name;
const mood      = user.mood;
const intensity = user.intensity;

// With destructuring (clean)
const { name, mood, intensity } = user;

console.log(name, mood, intensity); // "Aditya" "Good" 7
📂 In ManaSarathi

Controllers use destructuring to unpack req.body:
const { mood, intensity, trigger } = req.body;

🧠 Active Recall Questions

Q1: What is the difference between const and let?
Answer: const declares a variable that cannot be reassigned after its initial value is set. let declares a variable that CAN be reassigned. Use const by default, and only use let when you know the value will change.
Q2: What does .filter() return?
Answer: It returns a new array containing only the items from the original array for which the callback function returned true. The original array is NOT modified.
Q3: Rewrite this without destructuring, using dot notation:
const { mood, intensity } = req.body;
Answer:

const mood = req.body.mood;
const intensity = req.body.intensity;
