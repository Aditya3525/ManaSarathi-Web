# 📚 Learning Resources: Backend Foundation

High-quality basic-to-advanced references to accompany our step-by-step learning:

---

## 1. JavaScript Fundamentals
*   **[JavaScript.info](https://javascript.info/)**: The best, most comprehensive guide on modern JavaScript (ES6+). Starts from the absolute basics (variables) to advanced concepts (promises, event loop).
*   **[MDN JavaScript Guide](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Guide)**: Mozilla's official developer network guide, excellent for standard syntax lookup.

## 2. TypeScript Basics
*   **[TypeScript in 5 Minutes](https://www.typescriptlang.org/docs/handbook/typescript-in-5-minutes.html)**: Quick start guide for programmers new to typed languages.
*   **[TypeScript Playgrounds](https://www.typescriptlang.org/play/)**: Write TypeScript online and see the compiled JavaScript output in real time.

## 3. Node.js & HTTP basics
*   **[Node.js Introduction](https://nodejs.org/en/learn/getting-started/introduction-to-nodejs)**: Official introductory guide explaining how Node.js runs JS code.
*   **[What is HTTP? (MDN)](https://developer.mozilla.org/en-US/docs/Web/HTTP/Overview)**: Explains requests, responses, headers, and status codes.
