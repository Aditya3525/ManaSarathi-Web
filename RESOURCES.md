# 📚 Learning Resources: ManaSarathi Backend

Here are high-quality, high-trust reference materials to ground your understanding. Refer to these whenever you need to look up concepts or syntax.

---

## 1. Node.js & Express.js (The Runtime & Server)
*   **[Express.js Official Guide](https://expressjs.com/en/guide/routing.html)**: The official documentation for Express routing. Essential to understand how HTTP requests are mapped to handlers.
*   **[MDN Web Docs: Express/Node introduction](https://developer.mozilla.org/en-US/docs/Learn/Server-side/Express_Nodejs/Introduction)**: A thorough, beginner-friendly introduction to Node and Express.

## 2. TypeScript (The Safe Language)
*   **[TypeScript for Beginner Programmers](https://www.typescriptlang.org/docs/handbook/typescript-from-scratch.html)**: Learn the basic syntax of types, interfaces, and compiler concepts.
*   **[Total TypeScript (Matt Pocock)](https://www.totaltypescript.com/tutorials)**: High-quality interactive tutorials for modern TypeScript developers.

## 3. Databases & ORM (Prisma & PostgreSQL)
*   **[Prisma Schema Reference](https://www.prisma.io/docs/concepts/components/prisma-schema)**: How Prisma schemas, models, and relationships work.
*   **[PostgreSQL Tutorial](https://www.postgresqltutorial.com/)**: Excellent guide for understanding SQL relations, joins, and indexing.

## 4. Authentication & Security
*   **[JWT.io Introduction](https://jwt.io/introduction)**: A visual guide explaining the structure of JSON Web Tokens.
*   **[OWASP Top 10 Security Risks](https://owasp.org/www-project-top-ten/)**: The gold standard for web security concepts (CSRF, XSS, rate-limiting, and validation).

## 5. Large Language Model Integration
*   **[Google Gemini API Docs](https://ai.google.dev/gemini-api/docs)**: Documentation for our backup/primary Gemini AI model interface.
*   **[OpenAI API Reference](https://platform.openai.com/docs/api-reference)**: Reference for the core GPT prompt/completion structure.
