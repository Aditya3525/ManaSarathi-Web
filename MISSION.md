# 🎯 Learning Mission: ManaSarathi Backend Mastery

## Why We Are Here
The primary goal is to **ace the Final Year Project evaluation** and confidently explain the ManaSarathi backend architecture, database schemas, and AI orchestration flow to external teachers/examiners.

## Target Audience & Background
- **Learner Profile**: Beginner-to-Intermediate developer.
- **Prior Knowledge**: Has written JavaScript/TypeScript; familiar with basic SQL and database concepts.
- **Key Need**: High-level structural comprehension + ability to explain *why* architectural choices were made (design patterns, security measures, LLM fallback resiliency).

## Key Learning Outcomes (The "Examiner Prep" Checklist)
By the end of this program, you will be able to:
1. Draw and explain the **architecture diagram** (Request/Response lifecycle).
2. Walk an examiner through the **Database Schema** (Prisma / PostgreSQL relationships).
3. Explain the logic, fail-safes, and fallback priority of the **AI Multi-Provider System** (the core LLM engine).
4. Detail the **security measures** implemented (JWT rotation, Helmet, rate limiting, sanitization).
5. Explain how tests and logs support reliability.
